# 📊 Customer Retention Intelligence Platform

An end-to-end **Tableau analytics suite** built on the Olist e-commerce dataset, following the **CRISP-DM methodology**. This project delivers a multi-dashboard view into sales performance, customer behavior, product trends, and churn risk — designed to help stakeholders make data-driven retention decisions.

---

## 🧭 Overview

The platform is broken into **5 interactive dashboards**, each focused on a specific business lens. All dashboards feature dynamic KPI cards, trend charts, maps, bubble charts, and interactivity via dashboard actions and parameters.

| Dashboard | Focus Area |
|---|---|
| 🏆 Executive Dashboard | High-level business KPIs & summary insights |
| 💰 Sales Dashboard | Revenue trends, orders, and performance metrics |
| 👥 Customer Dashboard | Customer segmentation, behavior & geography |
| 📦 Products Dashboard | Product-level performance & category insights |
| ⚠️ Churn Dashboard | Customer churn risk & retention indicators |

## 🖱️ How to View the Dashboards

1. Click any dashboard link above — it opens directly on **Tableau Public** in your browser.
2. Use the **tabs at the bottom** of the viz to switch between related dashboard sheets (if available).
3. Interact with the dashboard using:
   - 🔍 **Filters & Parameters** — refine data by region, time period, category, etc.
   - 🖱️ **Hover** over charts and maps to see detailed tooltips.
   - 🔗 **Dashboard Actions** — click on a chart element to filter related visuals automatically.
4. Use the **Download** icon (bottom-right toolbar) on Tableau Public to export the view as an image or PDF.
5. Best viewed on a **desktop/laptop screen** for full interactivity.

## 🛠️ Tools & Methodology

- **Tool:** Tableau Public/Desktop
- **Dataset:** Olist E-Commerce Dataset
- **Methodology:** CRISP-DM (Cross-Industry Standard Process for Data Mining)
- **Key Features:**
  - Multi-table relationships & data modeling
  - KPI cards with dynamic calculations
  - Trend & time-series analysis
  - Geographic mapping
  - Bubble charts for comparative analysis
  - Parameter-driven interactivity
  - Dashboard actions for cross-filtering
